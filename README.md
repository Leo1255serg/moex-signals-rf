# Сигналы РФ — инструкция для новичка (без git)

Ключи Telegram уже вшиты в `run.py` и `test_telegram.py`.  
Подписка GitHub **не нужна**. Всё делается через сайт в браузере.

Папка на компьютере, которую нужно загрузить:

`C:\Users\mi\Desktop\тестировачные разработки\Сигналы РФ\GitHubRF`

---

## Шаг 1. Создать репозиторий (хранилище)

1. Откройте сайт: https://github.com/new  
2. Войдите в свой аккаунт, если ещё не вошли.  
3. В поле **Repository name** напишите, например: `moex-signals-rf`  
4. Выберите **Public** (зелёная точка / переключатель Public).  
5. Галочки **НЕ ставьте**:
   - Add a README file — **выкл**
   - Add .gitignore — **None**
   - Choose a license — **None**
6. Нажмите зелёную кнопку **Create repository**.

Откроется почти пустая страница репозитория — так и должно быть.

---

## Шаг 2. Загрузить файлы с компьютера

1. На странице нового репозитория найдите ссылку/кнопку  
   **uploading an existing file**  
   (или меню **Add file** → **Upload files**).
2. Откройте на компьютере папку:

   `Сигналы РФ` → `GitHubRF`

3. **Выделите ВСЁ внутри GitHubRF** и перетащите в окно браузера GitHub:

   Обязательно должны попасть:
   - `run.py`
   - `test_telegram.py`
   - `requirements.txt`
   - `README.md`
   - `rf_model.pkl`
   - `nn_model.h5`
   - `scaler.pkl`
   - папка `data` (со всеми Excel внутри)
   - папка `.github` (внутри неё `workflows` → файл `moex_signals.yml`)

   Важно: папка `.github` на Windows часто **скрыта**.  
   Если её не видно:
   - Откройте Проводник → вкладка **Вид** → включите **Скрытые элементы**.
   - Или в адресной строке Проводника вставьте путь:

     `C:\Users\mi\Desktop\тестировачные разработки\Сигналы РФ\GitHubRF\.github`

   и перетащите эту папку отдельно.

4. Внизу страницы в поле Commit message можно оставить как есть  
   (например `Add files via upload`).
5. Нажмите зелёную кнопку **Commit changes**.

Подождите, пока файлы загрузятся. После этого на главной странице репозитория должны быть видны файлы.

---

## Шаг 3. Включить автозапуск (Actions)

1. Вверху репозитория откройте вкладку **Actions**.  
2. Если GitHub спросит разрешение — нажмите  
   **I understand my workflows, go ahead and enable them**  
   (или похожую зелёную кнопку).  
3. Слева в списке workflows нажмите **MOEX Signals RF**.  
4. Справа нажмите кнопку **Run workflow**.  
5. В выпадающем меню:
   - пункт **telegram_only** поставьте в **true** (это тест Telegram);
   - нажмите зелёную **Run workflow**.
6. Через 1–3 минуты обновите страницу: сверху появится новый запуск (жёлтый кружок → потом зелёная галочка).  
7. Откройте Telegram — должно прийти сообщение:

   `✅ Тест Сигналы РФ (GitHub Actions)...`

Если сообщение пришло — бот работает.

8. Снова **Run workflow**, но теперь **telegram_only = false** — это полный расчёт сигналов (может занять 10–20 минут).  
   В конце снова придут сообщения в Telegram.

---

## Шаг 4. Дальше ничего делать не нужно

Каждый будний день около **10:30 по Москве** GitHub сам:

1. запустит скрипт;
2. проверит, торговый ли день на ММВБ;
3. посчитает сигналы и напишет в Telegram;
4. остановится.

В праздники ММВБ и в выходные работа пропускается.

Проверить историю запусков всегда можно во вкладке **Actions**.

---

## Если что-то пошло не так

| Проблема | Что сделать |
|---|---|
| Нет вкладки Actions / workflow не виден | Значит не загрузили папку `.github`. Включите скрытые файлы и загрузите её ещё раз через **Add file → Upload files**. |
| Run workflow красный (ошибка) | Откройте красный run → нажмите на job → смотрите красные строки лога. Часто помогает просто **Re-run**. |
| В Telegram тишина | Напишите боту любое сообщение сами (например `/start`), затем снова Run workflow с `telegram_only = true`. |
| Не вижу `.github` на диске | Вид → Скрытые элементы, путь выше в инструкции. |

- Расписание: пн–пт, ~10:30 МСК  
- Доп. проверка торгового дня ММВБ  
- Сигналы и закрытия позиций → в ваш Telegram
